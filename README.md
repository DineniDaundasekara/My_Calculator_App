# 📱 Calculator App

A simple and user-friendly calculator Android application developed using **Kotlin** in **Android Studio**. This app performs basic arithmetic operations and provides a clean UI for an intuitive user experience.

---

## 🚀 Features

- Basic arithmetic operations:  
  ➕ Addition  
  ➖ Subtraction  
  ✖️ Multiplication  
  ➗ Division  
- Clear display and reset function  
- Responsive and mobile-friendly UI  
- Error handling for invalid operations (e.g., divide by zero)

---

## 🛠️ Technologies Used

- **Language:** Kotlin  
- **IDE:** Android Studio  
- **UI Design:** XML  
- **Architecture:** MVVM
